# Manoj Sriram — React Portfolio

Typography update: **Inter** is used for body text and UI, while **Manrope** is used for headings and display text. Both are clean sans-serif families selected for a modern technical portfolio and strong screen readability.

## Run locally

```bash
npm install
npm run dev
```

The layout, colors, sections, project content, and assets are preserved. Google Fonts are loaded online; local fallback fonts are included in the CSS stack.


## Accessible gradient palette
The site uses a consistent soft lavender, icy-blue and pale-violet gradient across sections. Dark navy typography and high-contrast white project surfaces improve readability. Contact logos remain at their original colors and are displayed without cards or dark hover filters.
